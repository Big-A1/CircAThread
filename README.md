# CircAThread

CircaThread is a Free, Open-Source analytical suite for analysis of Acrimetrics LumiCycle Bioluminescence data. 

To start, export your traces from the LumiCycle into LumiCycle analysis software downloadable from https://actimetrics.com/downloads/lumicycle/
Following this step, export your traces as "data as text(subtracted)" and check the csv files ahve appeared in your folder under the "analysis" tab
From here import the  csv files into the three CircAThread modules either through the file explorer menu or via drag and drop to begin analysis
